## Reporting a Vulnerability

The `minish` team takes security and disaster-recovery reliability seriously.

If you discover a security vulnerability, buffer overflow, privilege escalation, or unexpected memory corruption:

1. **Do NOT open a public GitHub issue**.
2. Please report the issue privately to the project maintainers via GitHub Security Advisories or project security contacts.
3. Include:
   - Command line or input script reproducing the issue.
   - Operating system and kernel version (`uname -a`).
   - GCC version and build flags used to compile `minish`.
   - GDB backtrace or Valgrind log if available.

We will acknowledge receipt within 48 hours and work with you to release a coordinated security fix.
